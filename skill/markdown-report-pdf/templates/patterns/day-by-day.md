# 模式 D · 全包行动表 (D1-Dn)

> 适用: 行程表 / 时间表 / 7-N 天活动安排
> 触发词: "行程" / "时间表" / "每天" / "D1" / "几点"
> M3 vision 评分基线: **8.5/10**
> 实战案例: 见 `references/v5-case-study.md` 案例 4

---

## 模板

```markdown
## {{日期}} 全包行动表 (D1-D{{N}} 一张)

| 日期 | 时间 | {{航班/行动}} | 行程 | 住宿 | 餐厅推荐 |
|---|---|---|---|---|---|
| **D1 {{日期}}** | {{时间}} | {{事件}} | {{事件}} | {{酒店}} | {{餐厅 ⭐X.X · ¥XX-XX · 招牌菜}} |
| | {{时间}} | {{事件}} | | | |
| | {{时间}} | {{事件}} | | | |
| **D2 {{日期}}** | {{时间}} | {{事件}} | {{事件}} | {{酒店}} | {{餐厅}} |
| ... | | | | | |
| **Dn {{日期}}** | | | | | |
```

## 字段说明

| 列 | 必填 | 备注 |
|---|---|---|
| 日期 | ✅ | D1 / D2 / ... 强烈建议加具体日期 ({{M.D}} + 周几) |
| 时间 | ✅ | 24h 制 (10:05 / 23:55) |
| 航班/行动 | ✅ | 跨城用 ✈️/🚄, 市内用 emoji 或文字 |
| 行程 | ✅ | 景点/活动/项目名 |
| 住宿 | 跨城必 | 酒店名 (已订)/ 区域 (待定) |
| 餐厅 | 自由行必 | 至少 1 家 + 评分 + 价位 + 招牌 |

## 关键设计点

### 1. D1 首行用粗体 + 多行 cell

```
| **D1 7.4 周六** | 10:05 | ✈️ {{航班 A}} 起飞 | — | — | — |
|                  | 15:25 | {{中转地}} 抵达   | — | — | — |
|                  | 18:30 | ✈️ {{航班 B}} 起飞 | — | — | — |
|                  | 21:30 | {{目的地}} 抵达 | — | {{住宿(待定)}} | {{餐厅 ⭐X.X · ¥XX-XX}} |
```

**首行加粗** 让用户一眼看到 Day 起点
**后续行同一 Day 留空日期列** 减少视觉噪声

### 2. 6 列不多不少

- < 5 列 → 信息密度不够
- > 6 列 → 难扫描
- 6 列是黄金: 日期/时间/行动/行程/住宿/餐厅

### 3. 餐厅列是亮点

- 含 ⭐ 评分 + ¥ 价位 + 招牌菜
- 强场景标签 (24h · 凌晨首选)
- 一眼能决定 "今晚吃哪家"

## 跨场景模板

未来任何行程表, 直接套 6 列:

| 场景 | 6 列 | 备注 |
|---|---|---|
| 国内自由行 | 日期/时间/行动/景点/酒店/餐厅 | 同模板 |
| 出境跟团 | 日期/时间/航班/项目/酒店/餐厅 | 第 3 列改为"航班" |
| 商务考察 | 日期/时间/会议/接送/酒店/餐厅 | 强化"会议"列 |
| 邮轮行程 | 日期/时间/港口/岸上游/舱位/餐厅 | 港口替代景点 |
| 徒步穿越 | 日期/时间/路段/海拔/营地/补给 | 海拔替代景点 |

## M3 vision 反馈 (V5.1 D1)

> "日期 + 时间 + 行动 + 行程 + 住宿 + 餐厅 6 列对齐, 时间轴清晰"
> "首行加粗 + 后续留空 = 视觉锚点 + 减少噪声"
> "餐厅列带 ⭐ 评分是亮点, 一眼能选"
