# 模式 C · 分级处置表

> 适用: 延误 / 风险 / 响应时间 / 任何"按级别/时长"分类
> 触发词: "分级" / "分时长" / "不同情况" / "等级"
> M3 vision 评分基线: **9/10**
> 实战案例: 见 `references/v5-case-study.md` 案例 3

---

## 模板

```markdown
### {{N}}.{{M}} {{场景}}分级处置

| 时长 | 你的权益 | 行动 |
|---|---|---|
| < {{N1}}h | {{权益 1}} | {{行动 1}} |
| {{N1}}-{{N2}}h | {{权益 2}} | {{行动 2}} |
| {{N2}}-{{N3}}h | {{权益 3}} | {{行动 3}} |
| {{N3}}h+ | {{权益 4}} | {{行动 4}} |
| 取消 | {{权益 5}} | {{行动 5}} |
```

## 字段说明

| 字段 | 必填 | 备注 |
|---|---|---|
| 时长 | ✅ | 升序 (短 → 长), 最后一行是 "取消" 兜底 |
| 你的权益 | ✅ | 写明国际/国内差异, 引用法规/票规 |
| 行动 | ✅ | 找柜台 / 要食物券 / 启动 Plan B |

## 设计原则

1. **时长单调递增** (用户能直观读)
2. **权益递进** (无 → 餐食 → 通讯 → 住宿)
3. **行动有触发条件** (什么时长做什么, 不模糊)
4. **底线 + 加分项** 标粗强调
5. **取消** 永远放最后一行 (兜底)

## 跨场景分档参考

未来任何"分级别"任务, 直接套模板 + 替换分档值:

| 场景 | 时长分档 |
|---|---|
| 航班延误 | < 2h / 2-4h / 4-6h / 6h+ / 取消 |
| 酒店超售 | < 30min / 30min-2h / 2-6h / 6h+ / 取消 |
| 台风预警 | 蓝 / 黄 / 橙 / 红 / 取消 |
| 雨量 | 小雨 / 中雨 / 大雨 / 暴雨 / 极端 |
| 景区拥挤度 | 空闲 / 适中 / 较挤 / 爆满 / 限流 |
| 套餐温度 | 冷 / 凉 / 常温 / 热 / 烫 |

## 跨场景权益模板

| 时长档 | 航班权益 | 酒店权益 | 景区权益 |
|---|---|---|---|
| < N1 | 无补偿 | 协商 | 正常进入 |
| N1-N2 | 餐食/水 | 升级 | 排队预约 |
| N2-N3 | 通讯/餐食 | 退款50% | 限流 |
| N3+ | 免费住宿 | 全额退款 | 关闭 |
| 取消 | 退款/改签 | 转订他店 | 改日期 |

## M3 vision 反馈 (V5.1)

> "时长 + 权益 + 行动 三列对齐, 边界清晰"
> "取消放最后一行, 兜底意识强"
