# Eight Confirmations — 8 字段一次性锁定机制

> 两段共 8 字段: **A 段 4 个出行参数**(必问) + **B 段 4 个 PPT 风格**(默认)
> 一次问, **不要分步问**——用户最烦连环问

---

## 为什么不要分步问

- 用户最烦"你想要 A 还是 B / 还要 C 吗"连环问
- 决策手册是"展示+说服"产物,**用户已经决定要 PPT,只是在等**
- **8 字段都在内部设计完,只在末尾给 1 句"要不要改 X"**

---

## A 段 4 字段(出行参数) ⚠ **必问**

| # | 字段 | 来源 | 默认值 | 替代 |
|---|---|---|---|---|
| A1 | **出发城市** | URL `?city=2` | 上海(2)/北京(1)/广州(32) | 携程 departCityId 码表 |
| A2 | **出发日期** | **必问** | 用户口头给(本例 2026-07-04) | 周内 / 周末 / 国庆 |
| A3 | **返程日期** | **必问** | 用户口头给(本例 2026-07-10) | 行程天数 = toDate - fromDate |
| A4 | **人数 + 客群** | **必问** | 2 成人 / 朋友 / 双人 | 亲子 / 蜜月 / 退休 / 独行 |

**为什么必问**:
- A2/A3 不在产品页 URL 里,**携程 m 端 SPA 默认展示"最近班期"**,**实际 7/4 班期是用户在页面下拉选的**
- **A2/A3 不预填** → **PPT 里价格日历是错的**(展示的不是用户实际要买的那个班期)
- A4 不预填 → **P22 客群分流 + 装备清单 + 决策矩阵写偏**

### A 段自动提取方法

**出发城市**(`city=2`):
- 携程 cityId 码表: 1=北京 / 2=上海 / 32=广州 / 477=深圳 / 17=成都 / 12=杭州 / 152=南京 / 130=武汉
- URL `https://vacations.ctrip.com/travel/detail/p69762187?city=2` → city=2 = 上海
- 不确定时问 1 句:"city=X = 上海对吗?"

**出发/返程日**:
- **用户口头给**(最常见) → 写进 spec
- **URL 里有 from/to** → 提取;否则**问 1 句**
- 7 日产品:**returnDate = departDate + 6** (6 晚)

**人数 + 客群**:
- 2 成人(默认,占 80%)
- 1 大 1 童(亲子,客群分流页不同)
- 2 大 2 童(亲子)
- 退休夫妻(慢节奏,装备不同)
- 蜜月(高星+浪漫)

## B 段 4 字段(PPT 风格) ✅ **默认即可,不用问**

| # | 字段 | 默认值 | 替代 |
|---|---|---|---|
| B1 | 画布 | 16:9 (ppt169) | 4:3 / 自定义 |
| B2 | 页数 | 26(高水准)/ 21(标准)/ 12(精简) | ≤10 / ≥30 |
| B3 | 风格 | editorial 杂志 / 海岛风 | corporate / playful / minimalist |
| B4 | 配色 | 海岛蓝绿 + 火山橙红(主) + 13 色板 | 商务蓝灰 / 中性米色 / 暗黑 |

**何时打断用户**(B 段只有 2 种):
- 客户/老板路演 → 翻 corporate
- 客户指定了 4:3 / 自定义画布

其他时候:**默认走完,末尾"要不要改风格/页数"一钩子**。

## 何时 A 段可省

- 用户明确给完整 4 字段(如:"7/4 上海 2 人 上海"): **不用问**
- 用户只给 URL 不给参数: **必问 A2/A3/A4**(A1 可从 URL 提)

---

## 失败案例(用户原话摘)

> "7/4-7-10 日" —— **A2/A3 已给**,但**没给 A4 客群** → 默认 2 成人/朋友
> "双人旅游" —— **A4 已给**,但**没给 A2/A3** → 必问出发日
