## 9. v4 7 大坑(踩过 2 次的本 session 教训)

1. **URL 必须拼 `&shoppingid=32hex`**:不带 → SPA 不触发 getShoppingDetail,`response` 监听 0 抓,`expect_response` timeout
2. **`page.on('response', ...)` 普通监听 0 命中**:携程 SPA 用 fetch + AbortController,必须用 `page.expect_response` 同步阻塞
3. **expect_response 一次只能等一个**:`for query in ['getShoppingDetail','getShoppingPrice']` 循环,每次重 `page.goto`
4. **`/tmp/inspect.py` 会抢 Python `import inspect`**!永远不要在 /tmp 写 `inspect.py`
5. **`/tmp/ctrip_*.py` 等文件名要和业务一致**,别起通用名(避免和 stdlib 冲突)
6. **write_file 在 heredoc / `***` 时会丢字符**!改用 Python + 读 .env(shell `export KEY=***` 会被 token 过滤改坏,**用 Node `process.env.X`**)
7. **`&` 在 SVG XML 必须 escape `&amp;`**,P20 "SECTION F · RISK & EXIT" 踩过
8. **3 路软链 `cp` 报 "are the same file"** 是对的(同 inode 硬链),不要重 link,改用 `ls -la` 确认
